## 📖 About

**Google Homepage Clone** is a frontend practice project that recreates the visual layout of the Google homepage using only **HTML5 and CSS3**.

The project focuses on understanding how a familiar real-world interface can be structured and styled without using JavaScript, frameworks, or external UI libraries.
